# سديم — صفحة "قريبًا"

مشروع Next.js 15 مستقل. صفحة واحدة ثنائية اللغة (عربي/إنجليزي) لوكالة سديم —
وكالة تسويق متعددة التخصصات مقرها الرياض. لا يوجد نموذج تسجيل بريد: التواصل
مباشر عبر البريد والهاتف وواتساب.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000  →  يحوّل تلقائيًا إلى /ar
```

للإنتاج:

```bash
npm run build && npm start
```

## البنية

```
src/
  middleware.ts           توجيه اللغة (يجب أن يبقى داخل src/ لا في الجذر)
  i18n/
    routing.ts            اللغات + اللغة الافتراضية + دالة الاتجاه dirOf
    request.ts            تحميل ملف الترجمة لكل طلب
    navigation.ts         Link / useRouter الواعية باللغة
  app/
    layout.tsx            الجذر — لا يعرف اللغة فيتركها للطبقة التالية
    [locale]/layout.tsx   <html lang dir> + الميتاداتا + تحميل الخط
    [locale]/page.tsx     الصفحة
    globals.css           توكنز الهوية + الفتحة المتحركة
  fonts/
    Heliopolis-*.woff2    خط الهوية — ثلاثة أوزان
  components/
    LanguageToggle.tsx    تبديل اللغة عبر المسار (تغيير URL حقيقي)
    ContactActions.tsx    بطاقات التواصل الثلاث
messages/
  ar.json  en.json        كل النصوص — لا نص مكتوب داخل المكوّنات
public/
  logo.svg  logo-icon.svg أصول العلامة
```

## تعديل النصوص

كل الكلام في `messages/ar.json` و`messages/en.json` فقط. لا يوجد نص مكتوب
داخل المكوّنات، فتعديل الصياغة لا يحتاج لمس الكود.

المفتاحان متطابقان في البنية — أي مفتاح تضيفه في أحدهما أضفه في الآخر
وإلا ظهر اسم المفتاح مكان النص.

## بيانات التواصل

البريد ونص الهاتف في `messages/*.json` تحت `contact`. أما رقم الاتصال الفعلي
ورابط واتساب فثابتان في `src/components/ContactActions.tsx`
(`PHONE_E164` و`PHONE_DIGITS`) — عدّلهما معًا عند تغيير الرقم.

## الهوية

| التوكن | القيمة | الاستخدام |
|---|---|---|
| `--color-brand` | `#1B4F91` | الأزرق الغامق — نص ومساحات مملوءة — تباين 6.89:1 |
| `--color-brand-deep` | `#123A6E` | التحويم والنص الصغير — تباين 9.55:1 |
| `--color-cream` | `#F0EBE6` | سطح الصفحة |
| `--color-ink` | `#111827` | النص الأساسي — تباين 14.98:1 |

الأزرق الغامق يجتاز AA لأي حجم نص، فيصلح للنص والتعبئة معًا — بخلاف
البرتقالي السابق (2.78:1) الذي كان محظورًا على النص.

### الفتحة

أيقونة سديم "تفريغ" — العصا ثقب لا تعبئة. الصفحة تستثمر ذلك: المربّع يمتلئ
بحقل لوني متحرك والعصا تبقى فراغًا يظهر منه لون الصفحة. نقاط `clip-path` في
`globals.css` مأخوذة من `public/logo-icon.svg` بلا تعديل هندسي.

### الخط

خط واحد للصفحة كلها: **HT Heliopolis** بأوزانه الثلاثة (300 / 400 / 500)،
ملفاته في `src/fonts` ويُحمَّل عبر `next/font/local` في
`app/[locale]/layout.tsx` — بلا أي استدعاء خارجي، فلا طلب شبكة إلى Google
ولا وميض خط. الخط يغطّي العربية واللاتينية والأرقام معًا.

لا تستخدم وزنًا خارج الثلاثة (مثل `font-extralight` أو `font-bold`) وإلا
اصطنعه المتصفّح وبان مشوّهًا.

## ملاحظات

- التتبّع الواسع والحروف الكبيرة مقصورة على اللاتينية (`.latin-caps`). تطبيقها
  على العربية يفصل وصلات الحروف فتتفكّك الكلمة.
- حقول النموذج سطر سفلي لا صندوق، والتركيز يُعلَن بتلوين السطر — الحلقة
  الصندوقية تتعارض مع الشكل.
- `prefers-reduced-motion` محترم: حركة الفتحة تتوقف.
